# minhhoang0122.github.io

The home page of `https://minhhoang0122.github.io/`. It points to [Bloxkeep](https://github.com/minhhoang0122/Bloxkeep)'s website, which lives at [/Bloxkeep/](https://minhhoang0122.github.io/Bloxkeep/) and is built from the Bloxkeep repo.

Why it exists: Google shows one site name for a whole host and reads it from the WebSite structured data on the host's own home page ([Google's docs](https://developers.google.com/search/docs/appearance/site-names)). Without this page, results from `/Bloxkeep/` were labelled "GitHub Pages documentation". The `name` in `index.html` is what Google is asked to show; keep it the same as the WebSite node in Bloxkeep's `site/pages.mjs`.

`googlea034151c637399c2.html` verifies the site in Google Search Console. Don't delete it.
